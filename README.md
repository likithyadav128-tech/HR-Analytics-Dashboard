# 📊 HR Analytics Dashboard

## 📌 Project Overview

The HR Analytics Dashboard is an end-to-end Data Analytics and Machine Learning project developed to analyze employee attrition and identify the factors influencing employee turnover.

The project includes data cleaning, exploratory data analysis (EDA), data visualization, SQL analysis, machine learning model development, and an interactive Power BI dashboard.

---

## 🎯 Objectives

- Analyze employee attrition patterns
- Identify departments with high attrition
- Study the impact of salary, age, job role, overtime, and job satisfaction
- Predict employee attrition using Machine Learning
- Build an interactive HR dashboard in Power BI
